# HTML/CSS CA - Rainydays

Project was to built an online store for outdoor jackets using HTML and CSS.
## Description

The rainydays project means to provide a full user flow form entering the website to completing a purchase. It should allow  the user to browse products, view details and complete a purchase throug a checkout process. 

The project features:

- A Product listing page
- Product detail page for one product
- Shopping cart
- Checkout process with checkout form
- And a confirmation page

## Built With

- HTML
- CSS
